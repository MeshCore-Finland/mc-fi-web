## MeshCore communities in Finland

Nationwide community channels:

- <a href={resources.discord}>Mesh Finland Discord</a>, especially #mc-general. The same Discord also hosts the Meshtastic community.
- <a href={resources.whatsapp}>WhatsApp group</a>
- Matrix room `#meshcore-finland:hacklab.fi`

These particular Discord, WhatsApp and Matrix channels are bridged: messages appear on all three platforms. Each platform may also have regional or topic-specific channels, but only the main channel is bridged. The bridge is maintained by volunteers and is not completely reliable. If your message does not appear on another platform, that is not intentional.

Finland's MeshCore network is not yet one continuous network. It consists of several local meshes, some connected permanently and others occasionally when radio propagation permits.

We have tried to collect the largest Finnish MeshCore communities in this section. If anything needs updating, or you know a local mesh community that would like to be listed, contact us on Discord or open a GitHub issue.

To find repeaters or coverage where you live or travel, start with the MeshMapper map. It is updated only through volunteers' wardriving measurements, so the map for your area may not be fully current.

- [Finland MeshMapper map](https://finland.meshmapper.net/)
- [Greater Pirkanmaa MeshMapper map](https://tmp.meshmapper.net/)
