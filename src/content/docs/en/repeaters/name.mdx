A recognizable name helps you and other users identify your repeater. Choose the interface you use; your choice carries through the steps within this language.

## 1. Change the name

<Tabs syncKey="interface">
  <TabItem label="Web GUI">

Connect the repeater to a supported web interface and open its device settings. Edit the name and save it. Available controls depend on the interface and firmware.

  </TabItem>
  <TabItem label="Mobile app">

Open the repeater’s administration view in your mobile app. Connect with your admin credentials, then edit and save its name where supported.

  </TabItem>

Connect to the repeater’s serial console. Use the commands below; they apply to repeater firmware, not the companion CLI protocol.

  </TabItem>
</Tabs>

## 2. Check the result

<Tabs syncKey="interface">
  <TabItem label="Web GUI">

Refresh the device settings and check that the saved name is displayed.

  </TabItem>
  <TabItem label="Mobile app">

Reopen the repeater’s administration view and check the name. A contact name may update after a new advertisement.

  </TabItem>
  <TabItem label="Command line">

Read the name back from the repeater:

```text
get name
```

  </TabItem>
</Tabs>

If the app or web interface does not expose this setting, use the serial console. The [official command reference](https://github.com/meshcore-dev/MeshCore/blob/main/docs/cli_commands.md) documents the repeater commands.
