MeshCore messages travel by radio. Your phone is the interface, while a companion device handles the radio connection.

## 1. Choose a device

Start with a device supported by MeshCore companion firmware. Before buying, check [the official flasher](https://flasher.meshcore.io) for supported hardware.

## 2. Install firmware and connect

Install companion firmware using the flasher, then pair the device with the MeshCore mobile app. Follow the device-specific instructions linked by the flasher.

## 3. Use the Finnish settings

Select the **EU/UK Narrow** preset and check the values:

## 4. Send your first message

Try a greeting on Public or #finland. A quiet contacts list does not necessarily mean there is no network nearby.
