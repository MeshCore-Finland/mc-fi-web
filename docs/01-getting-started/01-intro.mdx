# Welcome to MeshCore Finland

MeshCore is a simple, secure, off-grid mesh communications system built by a global community of enthusiasts. This site is the regional hub for the Finland community.

## About MeshCore

MeshCore enables decentralized, peer-to-peer communication without relying on centralized infrastructure. Perfect for:

- Emergency communication
- Remote area connectivity
- Privacy-focused messaging
- Community networks

Learn more at [meshcore.io](https://meshcore.io)
