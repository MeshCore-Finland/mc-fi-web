# Setup Guide

Get your MeshCore device up and running.

## Prerequisites

- MeshCore-compatible device (check supported hardware)
- USB cable for flashing
- Computer with internet connection

## Flash Firmware

Use the [MeshCore Flasher](https://flasher.meshcore.io) to install the latest firmware:

1. Download the flasher application
2. Connect your device via USB
3. Select your device model
4. Click "Flash"
5. Wait for completion

## Configure Device

After flashing, configure your device:

### WiFi Setup (optional)
Connect to your home WiFi for cloud sync features (optional).

### Node Name
Set a unique node name identifying your device in the mesh.

### Location
Enable GPS or manually set your coordinates for the mesh map.

## Verify Connection

Once configured:

1. Open [CoreScope Finland](https://corescope.meshcore.fi/#/map)
2. Look for your node on the map
3. Send a test message to confirm connectivity

## Troubleshooting

**Device not appearing on map**
- Check internet connection
- Verify device is powered on
- Try rebooting device

**Firmware flash fails**
- Ensure correct device model selected
- Try different USB cable
- Disable antivirus temporarily
