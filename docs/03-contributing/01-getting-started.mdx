# Contributing to MeshCore Finland

We welcome contributions from the community! Whether it's documentation, code, bug reports, or feature ideas, your help makes MeshCore stronger.

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn
- Git

### Setup

1. Fork and clone the repository


First fork the main project at https://github.com/MeshCore-Finland/mc-fi-web

then
```bash
git clone https://github.com/yourusername/mc-fi-web.git
cd mc-fi-web
```

2. Install dependencies
```bash
npm install
```

3. Start development server
```bash
npm run dev
```

4. Open http://localhost:5173

## Contribution Types

### Documentation

Documentation is in `/docs` as MDX files. Easy way to contribute!

**Add a new page:**
```
docs/section-name/page-name.mdx
```

Navigation auto-generates from folder structure.

**MDX syntax:**
```mdx
# Heading

Regular text with **bold** and *italic*.

```bash
code block
```

[Link text](https://example.com)
```

### Code Changes

**Component guidelines:**
- Functional components with hooks
- Props typed with TypeScript
- Use Tailwind for styling
- Keep components focused

**Theme colors:**
Use CSS variables for consistent theming:
```tsx
<div style={{ color: 'var(--color-text)' }}>
```

Available: `--color-heading`, `--color-text`, `--color-link`, `--color-bg`, `--color-surface`, `--color-border`

### Testing

Before submitting:

```bash
npm run build    # TypeScript check + build
npm run lint     # Lint code
```

Test in browser:
- Dev mode: `npm run dev`
- Both light and dark themes
- Mobile responsiveness

## Git Workflow

1. Create a branch
```bash
git checkout -b feature/your-feature
```

2. Make changes and commit
```bash
git add .
git commit -m "Clear, concise commit message"
```

3. Push and create PR
```bash
git push origin feature/your-feature
```

Then open a pull request on GitHub.

## PR Requirements

- Tests pass: `npm run build && npm run lint`
- Responsive design works
- Both light/dark themes working
- Clear title and description
- Link related issues
